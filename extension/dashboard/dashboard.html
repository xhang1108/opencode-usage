Model Rate Settings

Each rule matches by exact model name. Rates are USD per million tokens. Each version sets an "effective from" time (leave empty = effective from the earliest, stored in UTC, converted automatically on input); versions are ordered by effective time: each version applies until the next version's effective time, and the last version is permanent. Billing mode is Flat or Time-based; Time-based only requires filling in the Peak windows (select weekdays + start/end times), and off-peak is automatically the remaining time. Tiers split low/high by input+cacheRead total context. Settings are stored locally and are overwritten by new defaults on version upgrade.
